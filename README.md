# VersatileAI

Welcome to VersatileAI! This is a multi-agent verification engine.
**Live Demo:** [https://versatile-ai-delta.vercel.app/](https://versatile-ai-delta.vercel.app/)

## Overview

VersatileAI orchestrates multiple specialized AI agents that can plan, research, write, verify, and critique tasks before delivering a final result.

## Running Locally

### Backend
1. `cd backend`
2. `pip install -r requirements.txt`
3. Set your environment variables in `.env`
4. `python main.py`

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev`

Visit `http://localhost:3000` to see the app in action!
